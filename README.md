# Context Keeper

تطبيق Android لحفظ سياق محادثات ChatGPT من تطبيق Android نفسه باستخدام Android Accessibility Service.

## الهدف

- محادثة جديدة: تشغيل التسجيل مرة واحدة ثم استخدام ChatGPT طبيعيًا. النصوص التي تظهر في شجرة إمكانية الوصول يتم التقاطها وحفظها تدريجيًا.
- محادثة قديمة: الذهاب إلى بداية المحادثة، تشغيل الالتقاط، ثم التمرير. يلتقط التطبيق لقطة فورية مع لقطات مؤجلة بعد التمرير حتى تستقر الواجهة.
- منع التكرار باستخدام SHA-256 مع نطاق الجلسة بدل الاعتماد على إعادة فحص ملف كامل.
- حفظ الرسائل في SQLite مع فهرسة، حتى لا تتطلب إضافة رسالة جديدة إعادة كتابة المحادثة كاملة.
- Queue تسلسلي للكتابة يمنع عمليات التخزين البطيئة من حجز callback الخاص بإمكانية الوصول.
- تصدير Markdown وJSON بطريقة streaming، بحيث لا يحتاج التصدير إلى تحميل المحادثة كلها في الذاكرة.

## الأداء والموثوقية

الإصدار 0.2.0 لا يضع حدًا اصطناعيًا لعدد الحروف أو الرسائل. الحد العملي هو مساحة التخزين وموارد Android. مع ذلك لا يمكن لـAccessibility ضمان التقاط حالة لم تُكشف للخدمة أصلًا؛ Android يوضح أن الخدمة قد لا تكون على علم بكل تغيرات شجرة العقد وأن معلومات العقد قد تكون قديمة. لذلك يلتقط التطبيق عدة snapshots حول أحداث التمرير بدل الاعتماد على حدث واحد فقط.

## التقنية

- Kotlin عبر Built-in Kotlin في AGP 9.x
- Android Gradle Plugin 9.3.0
- Gradle 9.5.0 في GitHub Actions
- compileSdk 36 / targetSdk 36
- minSdk 26
- AccessibilityService
- SQLite مع فهارس session/sequence وsession/hash
- SHA-256 deduplication

## البناء

افتح المشروع في Android Studio حديث متوافق مع AGP 9.3.0 ثم Sync/Build.

GitHub Actions يبني المشروع تلقائيًا عند كل `push` إلى `main` أو `pull request`، ويضع APK التجريبي كـ Artifact عند نجاح البناء.

## الصلاحيات

يطلب التطبيق تفعيل خدمة إمكانية الوصول يدويًا من إعدادات Android. هذه الصلاحية حساسة: التطبيق يجب استخدامه فقط لتسجيل المحتوى الذي تقصده أنت من جهازك.
