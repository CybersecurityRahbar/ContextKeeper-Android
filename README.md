# Context Keeper

تطبيق Android لحفظ سياق محادثات ChatGPT من تطبيق Android نفسه باستخدام Android Accessibility Service.

## ما يفعله

- تسجيل محادثة جديدة أثناء استخدامها طبيعيًا.
- التقاط محتوى المحادثات القديمة أثناء التمرير دون الحاجة للضغط على زر النسخ لكل رسالة.
- التقاط فوري عند أحداث التمرير وتغيّر المحتوى مع أخذ عينات دورية أثناء التسجيل للمساعدة في التمرير السريع.
- حفظ تدريجي في SQLite بدل إعادة كتابة ملف JSON كامل مع كل لقطة.
- منع التكرار داخل كل جلسة باستخدام fingerprint مفهرس.
- الحفاظ على Markdown والأسطر الجديدة وتنسيق الأكواد قدر الإمكان بدل ضغط المسافات كما في الإصدارات السابقة.
- تصدير Markdown وJSON إلى مجلد تختاره أنت من مدير ملفات Android، مثل Downloads، باستخدام Storage Access Framework.

## حدود الاعتمادية

التطبيق لا يعتمد على النسخ اليدوي للرسائل. لكنه يعتمد على محتوى شجرة Accessibility التي يتيحها تطبيق ChatGPT للنظام. لذلك لا يمكن ضمان التقاط حالة واجهة لم تصل أصلًا إلى خدمة Accessibility. لتحسين الاحتمال أثناء التمرير السريع تستخدم الخدمة التقاطًا فوريًا وأخذ عينات دورية ومتأخرة.

## التخزين

بيانات الالتقاط الأساسية داخل قاعدة SQLite الخاصة بالتطبيق. أما ملفات التصدير فبعد اختيار مجلد التصدير تُكتب خارجه مباشرة عبر URI دائم يمنحه Android للمجلد المختار، لذلك لا يعتمد التصدير الجديد على `Android/data`.

## التقنية

- Kotlin عبر Built-in Kotlin في AGP 9.x
- Android Gradle Plugin 9.3.0
- Gradle 9.5.0 في GitHub Actions
- compileSdk 36 / targetSdk 36
- minSdk 26
- AccessibilityService
- SQLite مع فهارس للجلسة والتسلسل
- SHA-256 deduplication
- Storage Access Framework

## البناء

GitHub Actions يبني المشروع تلقائيًا عند كل `push` إلى `main` أو `pull request`، ويضع APK التجريبي كـ Artifact عند نجاح البناء.

## الصلاحيات

يطلب التطبيق تفعيل خدمة إمكانية الوصول يدويًا من إعدادات Android. هذه الصلاحية حساسة: التطبيق يجب استخدامه فقط لتسجيل المحتوى الذي تقصده أنت من جهازك.
