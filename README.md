# Context Keeper

تطبيق Android لحفظ سياق محادثات ChatGPT من تطبيق Android نفسه باستخدام Android Accessibility Service.

## الهدف

- محادثة جديدة: تشغيل التسجيل مرة واحدة ثم استخدام ChatGPT طبيعيًا. النصوص التي تظهر في شجرة إمكانية الوصول يتم التقاطها وحفظها محليًا.
- محادثة قديمة: الذهاب إلى أول المحادثة، تشغيل التسجيل، ثم التمرير. عند كل تغير/تمرير يحاول التطبيق قراءة النص المرئي وإضافته بدون تكرار.
- تصدير `Markdown` للنسخ إلى ملف السياق في GitHub.
- تصدير `JSON` للاستخدام الآلي لاحقًا.

## ملاحظة مهمة عن الإصدار الأول

استخراج النص من تطبيقات Android عبر Accessibility يعتمد على ما يتيحه التطبيق الهدف في شجرة Accessibility. لذلك تم جعل المستخرج heuristic وليس معتمدًا على معرفات خاصة غير موثقة لـ ChatGPT. في الاختبار الحقيقي قد نحتاج إلى معايرة اكتشاف الرسائل/الأدوار حسب إصدار تطبيق ChatGPT الذي لديك.

## التقنية

- Kotlin عبر Built-in Kotlin في AGP 9.x
- Android Gradle Plugin 9.3.0
- Gradle 9.5.0 في GitHub Actions
- compileSdk 36 / targetSdk 36
- minSdk 26
- AccessibilityService
- تخزين محلي ذري + SHA-256 لمنع التكرار

## البناء

افتح المشروع في Android Studio حديث متوافق مع AGP 9.3.0 ثم Sync/Build.

GitHub Actions يبني المشروع تلقائيًا عند كل `push` إلى `main` أو `pull request`، ويضع APK التجريبي كـ Artifact عند نجاح البناء.

## الصلاحيات

يطلب التطبيق تفعيل خدمة إمكانية الوصول يدويًا من إعدادات Android. هذه الصلاحية حساسة: التطبيق يجب استخدامه فقط لتسجيل المحتوى الذي تقصده أنت من جهازك.
